# Fix UX Gaps in Session Lifecycle + 404 Bug

## Overview

The dashboard has "dead air" gaps during session lifecycle transitions where users don't know what's happening. Additionally, there's a bug where subsequent messages 404 because the error message check doesn't match the actual API response.

**Problems**:
1. Gap between "Session resumed" message and actual Claude availability
2. Gap between sending a message and any visual feedback
3. ActivityGrid doesn't show resuming/starting/subagent states
4. 404 recovery fails because error check looks for "not found" but API returns "not running"
5. Subagent progress not reflected in ActivityGrid

## Scope

**In scope**:
- Add `resuming` and `starting` states to ActivityGrid
- Fix timing of "Session resumed" system message
- Fix 404 error check to trigger auto-resume
- Show subagent activity in ActivityGrid
- Improve loading indicator states

**Out of scope**:
- Resume timeout/retry UX
- Nested subagent depth indicators
- SSE reconnection handling improvements

## Approach

### 1. Fix 404 Bug (fn-11.1)
- Change error check from `includes('not found')` to check for `code === 'INSTANCE_NOT_RUNNING'` OR `includes('not running')`
- File: `WorkspaceInstance.svelte:968`

### 2. Add ActivityGrid States (fn-11.2)
- Add `'resuming'` state when `restarting` is true
- Add `'starting'` state when `instance.status === 'starting'`
- Pass these flags as props to ActivityGrid
- File: `ActivityGrid.svelte:35-63`

### 3. Fix "Session Resumed" Timing (fn-11.3)
- Move "Session resumed" system message to SSE `instance:started` handler
- Keep `restarting` flag true until `instance:started` SSE event
- Use reactive flag `isResuming` that tracks this state
- Files: `WorkspaceInstance.svelte:918-922, 979-984`, `instances.svelte.ts`

### 4. Add Subagent Progress to ActivityGrid (fn-11.4)
- Use `instances.getActiveSubagentsForInstance(instanceId)` in ActivityGrid
- Add `'subagent'` state when active subagents exist
- Show subagent count or activity pattern
- Files: `ActivityGrid.svelte`, `WorkspaceInstance.svelte`
