## Overview

Replace the traditional linear chat view with a node-based flow visualization using `@xyflow/svelte`. This enables visual representation of branching subagents, parallel execution, tool chains, and message forking - making the agent's execution graph comprehensible at a glance with an RTS/Total Commander-style semantic zoom system.

**Current State:**
- Linear chat view with ChatMessage components
- SubagentTree/SubagentBranch renders collapsible tree cards
- Messages have `parentToolUseId` for subagent association
- No graph visualization, relationships hard to trace

**Target State:**
- Default view: Remembered per-instance (flow or chat)
- Interactive flow graph with semantic zoom (3 levels)
- Secondary view: Traditional chat (preserved for familiarity)
- Branching subagents as stacked branches with color coding
- Tool chains visualized as grouped connected nodes
- Real-time updates with 60fps smooth animations
- Linear-inspired minimal, fast, polished aesthetic

## Design Decisions (from interview)

### Zoom Levels (RTS/Total Commander style)
1. **Overview (zoomed out)**: Icon + color status dot only
2. **Summary (mid zoom)**: Task title + tool count + current action indicator (real-time)
3. **Detail (zoomed in)**: Full content with markdown rendering

### Node Design
- **User messages**: Full text in node
- **Assistant responses**: Full content with markdown rendering
- **Tool nodes**: Group sequential tools, show icon + file/target when collapsed
- **Subagent nodes**: Stacked branches, max 3 levels visible (expand for more)
- **Styling**: Match dashboard theme, flat design (no shadows), rounded corners (modern), content-adaptive width (max 400px), user-configurable width

### Tool Results Display
All three methods available (user configurable):
- Hover preview (~200 chars)
- Click to expand inline
- Side panel for full content

### Streaming & Status
- In-progress tools: Pulsing border + spinner
- Failed tools: Red border + error icon
- Errors: Toast notification + highlight problem node

### Edges & Connections
- Smooth bezier curves
- Edge labels (token count, time delta, relationship type) - zoom-dependent visibility
- Color-coded branches (3-4 colors from theme: blue, green, purple, amber)
- Thicker main conversation path, lighter branches

### Navigation & Controls
- MiniMap: Always visible
- Control panel: Full (zoom +/-, fit, lock, export, settings)
- Auto-scroll: Always follow new messages
- View toggle: Header button + Ctrl/Cmd+G keyboard shortcut
- Transition: Slide animation between views
- Icons: MessageSquare (chat) / GitBranch (flow)

### Interactions
- Context menu (right-click): Copy content, Rewind to here, Branch from here, Jump to chat view
- Click subagent: Zoom into branch (canvas zooms/pans to focus)
- No multi-select for MVP
- No drag-to-reposition (dagre auto-layout only)
- No keyboard navigation for MVP

### Permissions & Costs
- Permission requests: Node glows + dialog overlay
- Cost display: Running total in instance header

### ActivityGrid Integration
- Embed in flow view header
- When viewing multiple instances, show ActivityGrid next to each for status

### Performance & Platform
- Target: 60fps smooth animations
- Platforms: Desktop + tablet + mobile (same responsive UI)
- Mobile: Nodes show overview level (zoom level 3) on small screens
- Requires live connection (no offline mode)
- Virtualized scrolling with auto-pan to new messages

### Stopped/Sleeping State
- No visual difference - just send message to wake up

### Deferred Features
- Text search in flow view
- Timeline/sequence view
- Touch gesture customization
- Export graph as image
- Message editing from flow

## Approach

### Node Granularity
Use **grouped nodes** with semantic zoom:
- `user` → Single user message node (full text at all zoom levels)
- `tool_group` → Grouped sequential tool chain node
- `subagent_group` → Subagent branch node (max 3 levels visible)
- `assistant` → Assistant response node (full markdown)
- `system` → System/status node

### Layout Strategy
- **dagre** with `TB` (top-to-bottom) direction
- Stacked branches for parallel subagents
- Color-coded branch paths (3-4 theme colors)
- Thicker main conversation path

### Data Flow
```
WebSocket sdk:message
  → sdk-message-handler
  → instances.addMessage()
  → $derived flowNodes/flowEdges
  → svelte-flow renders with semantic zoom
```

### View Architecture
```svelte
<WorkspaceInstance>
  <InstanceHeader>
    <ActivityGrid /> <!-- Embedded in header -->
    <ViewToggle /> <!-- MessageSquare | GitBranch icons -->
  </InstanceHeader>
  
  {#if viewMode === 'flow'}
    <FlowView messages={messages} />
  {:else}
    <ChatView messages={messages} />
  {/if}
</WorkspaceInstance>
```

## Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| svelte-flow Svelte 5 compatibility | Use latest @xyflow/svelte v1.x which supports runes |
| 60fps on mobile | Aggressive virtualization, defer detail rendering |
| Complex semantic zoom | CSS scale transforms + conditional rendering |
| Layout jumps on updates | Animate transitions, batch updates, incremental layout |
| Complex subagent nesting | Max 3 levels visible, expand for more |
| View state loss on switch | Preserve zoom/pan in store, restore on switch |
