## Fix 404 Error Check for Auto-Resume

**Problem**: When sending a message to an instance that's not running on the machine, the hub returns `"Instance not running on machine"` with code `INSTANCE_NOT_RUNNING`. However, the dashboard checks for `includes('not found')` which never matches, so auto-resume doesn't trigger.

**Location**: `WorkspaceInstance.svelte:966-993`

**Current code** (line 968):
```typescript
if (errMsg.toLowerCase().includes('not found'))
```

**Fix**: Check for the actual error message or code:
```typescript
if (
  errMsg.toLowerCase().includes('not found') ||
  errMsg.toLowerCase().includes('not running') ||
  error?.code === 'INSTANCE_NOT_RUNNING'
)
```

**Why this happens**:
- `instances.ts:297-299` returns `{ error: 'Instance not running on machine', code: 'INSTANCE_NOT_RUNNING' }`
- The error string doesn't contain "not found"

**Test**:
1. Start an instance, let it run
2. Stop the instance from another tab or let it sleep
3. Send a message to the stopped instance
4. Verify auto-resume triggers instead of showing error
