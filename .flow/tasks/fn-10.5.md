# fn-10.5 Command migration to WebSocket

## Description
Migrate dashboard commands from REST API to WebSocket.

## Commands to Migrate
1. **Spawn instance** - POST `/api/instances` → WS `instance.spawn`
2. **Send message** - POST `/api/instances/:id/send` → WS `instance.send`
3. **Stop instance** - POST `/api/instances/:id/stop` → WS `instance.stop`
4. **Permission response** - POST `/api/instances/:id/permission` → WS `permission.response`
5. **Question response** - POST `/api/instances/:id/question` → WS `question.response`

## Tasks
1. Add request/response tracking in dashboard WS client
   - `pendingRequests: Map<string, { resolve, reject, timeout }>`
   - Generate request IDs
   - Timeout handling (30s default)
2. Add command handlers in hub `dashboard-ws.ts`
3. Create dashboard API functions that send WS requests
4. Update UI components to use new WS-based API

## Done summary
## Summary

Migrated all dashboard commands from REST API to WebSocket using river.ts request/response semantics.

### Changes to stores (`apps/dashboard/src/lib/stores/index.svelte.ts`)

Added WebSocket command functions:
- `spawnInstance(params)` - Spawn a new instance via WS
- `sendInstanceMessage(params)` - Send message to instance via WS
- `stopInstance(params)` - Stop instance via WS
- `sendPermissionResponse(params)` - Send permission allow/deny via WS
- `sendQuestionResponse(params)` - Send question answers via WS
- `WebSocketNotConnectedError` - Exported error class

All commands use `adapter.request()` with 30s timeout.

### Changes to actions (`apps/dashboard/src/lib/actions.ts`)

Refactored to use WebSocket commands instead of Eden Treaty REST:
- `spawnInstance` → uses `wsSpawnInstance`
- `sendMessage` → uses `wsSendMessage`
- `stopInstance` → uses `wsStopInstance`

Project CRUD (create, update, delete) still use REST as they're not real-time critical.

### Changes to PermissionRequest component

Updated `handleAllow()` and `handleDeny()` to use `sendPermissionResponse()` instead of REST API call.

### Changes to ChatMessage component

Added props for question callbacks:
- `onQuestionSubmit`
- `onQuestionCancel`
- `isQuestionPickerActive`

### Changes to WorkspaceInstance component

Added question handlers:
- `handleQuestionSubmit()` - Sends answer via WS, updates store
- `handleQuestionCancel()` - Dismisses question from UI
- Wired callbacks to ChatMessage
