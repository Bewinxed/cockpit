## Add Resuming/Starting States to ActivityGrid

**Problem**: ActivityGrid only supports states `'idle' | 'thinking' | 'streaming' | 'tool_use' | 'permission' | 'error' | 'success'`. During session resume or startup, it shows `idle` which doesn't indicate anything is happening.

**Location**: `ActivityGrid.svelte:35-63` (`computeGridState` function)

**Changes needed**:

1. **Add new states** to the type:
```typescript
type GridState = 'idle' | 'thinking' | 'streaming' | 'tool_use' | 'permission' | 'error' | 'success' | 'resuming' | 'starting';
```

2. **Add props** to receive lifecycle state:
```typescript
interface Props {
  // existing...
  isResuming?: boolean;
  isStarting?: boolean;  // instance.status === 'starting'
}
```

3. **Update `computeGridState`** to check these first:
```typescript
function computeGridState(): GridState {
  if (isResuming) return 'resuming';
  if (isStarting) return 'starting';
  // existing logic...
}
```

4. **Add visual patterns** for new states:
- `resuming`: Pulsing/breathing pattern (slower than thinking)
- `starting`: Sequential activation pattern

5. **Update WorkspaceInstance.svelte** to pass these props:
```svelte
<ActivityGrid
  {streaming}
  {lastMessage}
  isResuming={restarting}
  isStarting={instance?.status === 'starting'}
/>
```
