## Add Subagent Progress to ActivityGrid

**Problem**: When a Task tool spawns a subagent, ActivityGrid doesn't reflect this activity. It may show `idle` or `thinking` but doesn't indicate subagent work is happening.

**Locations**:
- `ActivityGrid.svelte:35-63` - `computeGridState()`
- `instances.svelte.ts:565-570` - `getActiveSubagentsForInstance()` exists but unused in ActivityGrid
- `WorkspaceInstance.svelte` - Needs to pass subagent info to ActivityGrid

**Implementation**:

1. **Add `subagent` state** to ActivityGrid:
```typescript
type GridState = ... | 'subagent';
```

2. **Add prop** for active subagent count:
```typescript
interface Props {
  // existing...
  activeSubagentCount?: number;
}
```

3. **Update `computeGridState`**:
```typescript
function computeGridState(): GridState {
  // After checking resuming/starting...
  if (activeSubagentCount && activeSubagentCount > 0) {
    return 'subagent';
  }
  // existing logic...
}
```

4. **Add visual pattern** for subagent state:
- Could be a variant of `tool_use` with different animation
- Or a "branching" visual to indicate parallel work
- Color could indicate depth (1 subagent vs multiple)

5. **Pass from WorkspaceInstance**:
```svelte
<script>
  const activeSubagents = $derived(
    instances.getActiveSubagentsForInstance(instanceId)?.filter(s => s.status === 'running') ?? []
  );
</script>

<ActivityGrid
  {streaming}
  {lastMessage}
  activeSubagentCount={activeSubagents.length}
/>
```

**Note**: Subagent state should probably have lower priority than `streaming` or `tool_use` since those indicate direct activity. The priority order might be:
1. `error` / `permission` (blocking states)
2. `streaming` (active output)
3. `tool_use` (active tool)
4. `subagent` (background work)
5. `thinking` (waiting)
6. `resuming` / `starting` (lifecycle)
7. `idle` / `success`
