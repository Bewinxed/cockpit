# fn-12.1: Install @xyflow/svelte and dagre

Install the svelte-flow library and dagre layout engine.

## Steps

1. Add dependencies to `apps/dashboard/package.json`:
   ```bash
   cd apps/dashboard && bun add @xyflow/svelte @dagrejs/dagre
   ```

2. Verify Svelte 5 compatibility - @xyflow/svelte v1.x uses runes

3. Add CSS import to root layout or a shared styles file:
   ```typescript
   import '@xyflow/svelte/dist/style.css';
   ```

4. Run `bun install` from root

## Files to modify

- `apps/dashboard/package.json` - Add dependencies
- `apps/dashboard/src/routes/+layout.svelte` or shared CSS - Import styles
