## Summary

Created WebSocket endpoint `/ws/dashboard` for dashboard clients using river.ts format.

**Wire format:**
```typescript
// Events (hub → dashboard)
{ type: "sdk:message", data: {...} }

// Requests (dashboard → hub)  
{ type: "instance.spawn", data: {...}, id: "req-123" }

// Responses (hub → dashboard)
{ type: "instance.spawn", data: { instanceId: "..." }, id: "req-123" }
```

**Implementation:**
- `packages/hub-server/src/api/dashboard-ws.ts` - New file with:
  - `createDashboardWsRoutes()` - Elysia WS handler
  - `broadcastToDashboards()` - Send event to all connected dashboards
  - Client registry with HMR persistence
  - Command handlers: spawn, send, stop, permission.response, question.response

**Key design decisions:**
- Uses river.ts format (not JSON-RPC 2.0) as decided in fn-10 interview
- Separate from agent WebSocket (/ws/hub) which still uses JSON-RPC 2.0 for now
- Commands forward to agents via existing JSON-RPC protocol (bridge pattern)
