## Description
# fn-12.3: Create custom node components with semantic zoom

Create custom node components for each message type with 3-level semantic zoom support.

## Node Types

1. **UserMessageNode** - User input messages
   - All zoom levels: Full text content
   - Style: Distinct left-aligned, theme accent

2. **AssistantMessageNode** - AI responses
   - Overview: Icon + status dot
   - Summary: First line preview
   - Detail: Full markdown rendering
   
3. **ToolNode** - Grouped sequential tool invocations
   - Overview: Tool icon + status dot
   - Summary: Icon + file/target (e.g., "Read • src/auth.ts")
   - Detail: Full tool info + result preview
   - Features: Hover preview, click expand, side panel (configurable)
   - Streaming: Pulsing border + spinner
   - Error: Red border + error icon

4. **SubagentNode** - Subagent branches
   - Overview: Agent type icon + color status dot
   - Summary: Type + tool count + current action (real-time)
   - Detail: Type + status + duration + nested preview
   - Max 3 levels visible, "expand" for deeper
   - Click zooms into branch

5. **SystemMessageNode** - System/status messages
   - Compact, informational style

## Semantic Zoom Implementation

```svelte
<script>
  import { useStore } from '@xyflow/svelte';
  
  const { zoom } = useStore();
  
  const zoomLevel = $derived(
    $zoom < 0.5 ? 'overview' : 
    $zoom < 1.0 ? 'summary' : 
    'detail'
  );
</script>

{#if zoomLevel === 'overview'}
  <OverviewView />
{:else if zoomLevel === 'summary'}
  <SummaryView />
{:else}
  <DetailView />
{/if}
```

## Node Types

1. **UserMessageNode** - User input messages
   - Blue left border
   - Avatar or "You" label
   - Message content (truncated if long)
   - Timestamp
   
2. **AssistantMessageNode** - Claude responses
   - Purple left border  
   - "Claude" label
   - Markdown content preview
   - Model badge if available
   
3. **ToolNode** - Tool invocations (grouped)
   - Orange/amber styling
   - Tool name and icon
   - Status indicator (pending/success/error)
   - Collapsible tool input preview
   - Uses existing `getToolGlance()` utility
   
4. **SubagentNode** - Task tool spawning subagent
   - Teal/cyan styling
   - Subagent type (Explore, Plan, etc.)
   - Status and elapsed time
   - Expandable to show nested flow
   
5. **SystemMessageNode** - System/status messages
   - Gray styling
   - Compact display
   - Different icons per subtype
