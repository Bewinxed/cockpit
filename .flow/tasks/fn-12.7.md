# fn-12.7: Handle real-time streaming in flow nodes

Make flow view update smoothly during message streaming.

## Challenge

During streaming:
- New messages arrive rapidly via WebSocket
- Content accumulates in `StreamingMessage.contentBlocks`
- Need to update node content without layout thrashing

## Approach

1. **Separate streaming state from node position**
   - Node positions only recalculate on new nodes, not content updates
   - Content updates use `useSvelteFlow().updateNodeData()`

2. **Streaming content in nodes**
   ```svelte
   <!-- AssistantMessageNode -->
   <script>
     let { data }: NodeProps = $props();
     
     const streamingContent = $derived(
       instances.getStreamingContent(data.instanceId, data.messageId)
     );
     
     const displayContent = $derived(
       streamingContent || data.message.content
     );
   </script>
   ```

3. **Batch updates**
   - Use `requestAnimationFrame` to batch rapid updates
   - Debounce layout recalculation

## Implementation

Add to FlowView:

```svelte
<script>
  import { instances } from '$lib/stores';
  
  // React to streaming state
  const streamingState = $derived(instances.getStreamingState(instanceId));
  
  // Only relayout when node count changes, not content
  let lastNodeCount = 0;
  
  $effect(() => {
    if (nodes.length !== lastNodeCount) {
      lastNodeCount = nodes.length;
      // Trigger relayout
    }
  });
</script>
```
