## Description
# fn-12.8: Implement subagent branch nodes with expansion

Create expandable subagent nodes that show nested execution flow.

## Challenge

Subagents (Task tools) spawn child executions with their own messages. Current representation:
- `SubagentState.messages[]` contains tool invocations within subagent
- `SubagentState.parentSubagentId` links nested subagents
- Messages have `parentToolUseId` linking to parent Task tool

## Design

**Collapsed state (default):**
- Compact card showing subagent type, status, elapsed time
- Tool count badge
- Expand button

**Expanded state:**
- Full nested flow graph inline
- Shows tools and nested subagents
- Collapse button

## Implementation

1. **SubagentNode component**

```svelte
<script>
  import { Handle, Position, type NodeProps } from '@xyflow/svelte';
  import { instances } from '$lib/stores';
  
  let { id, data }: NodeProps = $props();
  let expanded = $state(false);
  
  const subagent = $derived(instances.getSubagent(data.toolUseId));
  const childMessages = $derived(subagent?.messages || []);
  const nestedSubagents = $derived(
    instances.getChildSubagents(data.toolUseId)
  );
</script>

<Handle type="target" position={Position.Top} />

<div class="subagent-node" class:expanded>
  <header>
    <span class="type-badge">{subagent?.subagentType}</span>
    <span class="status">{subagent?.status}</span>
    <button onclick={() => expanded = !expanded}>
      {expanded ? 'Collapse' : 'Expand'}
    </button>
  </header>
  
  {#if expanded}
    <div class="nested-flow">
      <!-- Recursive mini flow view -->
      <NestedFlowView messages={childMessages} />
    </div>
  {/if}
</div>

<Handle type="source" position={Position.Bottom} />
```

2. **Parallel subagent visualization**
   - When multiple Task tools run simultaneously
   - Show as side-by-side branches
   - Use dagre `compound: true` or manual column layout

3. **Branch merging**
   - When subagent completes, edge connects back to main flow
   - Visual indicator of completion status
